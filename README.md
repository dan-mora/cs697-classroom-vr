# VR Whiteboard

A small VR demo for Meta Quest made in Unity: a pastel room with a wall-length
whiteboard, three markers (black, red, blue) and an eraser you can pick up and use.

## What you need

- **Unity 6**: the exact version is listed in `ProjectSettings/ProjectVersion.txt`.
  Install that version through Unity Hub, with **Android Build Support** included.
- A **Meta Quest** headset (tested on Quest 2).
- For testing from the editor: a Windows PC with the **Meta Horizon Link** app
  and a USB-C cable.

## Opening the project

1. Download or clone this repository.
2. In Unity Hub, choose **Add > Add project from disk** and select the folder.
3. Open it. The first open takes a few minutes while Unity rebuilds its cache.
4. In the Project window, open **Assets** and double-click **whiteboard-scene**.

## Playing

**In the editor (over Link):** connect the headset with Link, then press **Play**.

**On the headset by itself:** turn on Developer Mode for the headset in the
Meta Horizon phone app, plug it in by USB, and choose
**File > Build Profiles > Android > Build and Run**. The app then appears in the
headset's Library under **Unknown Sources**.

## Controls

- **Grip button:** pick up a marker or the eraser.
- **Right thumbstick forward:** teleport.
- **Right thumbstick left/right:** turn.
- **Right thumbstick down:** crouch / stand up.

Touch a marker's tip to the whiteboard to draw. Press the eraser's felt against
the board to erase.

## Rebuilding the room

The room is generated by the **Room Builder** component on the **Room** object.
To change colors, sizes or lighting, edit its settings in the Inspector and choose
**⋮ > Build Room**.
